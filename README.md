# Rocket City Bar — демонстрационный сайт

Адаптивная концепция для фирменного бара Rocket City Brewery (Королёв, ул. Подмосковная, 7).

## Дизайн

Стилистическая адаптация визуального языка пивоварни: космическая тематика, контрастная типографика, яркие цвета этикеток, графитовый фон и сочетание синих/оранжевых цветов бара.

**Важное уточнение:** `assets/rocket-logo.svg` — вручную выполненная SVG-адаптация узнаваемой эмблемы (ракета внутри пивного бокала) по открытым визуальным референсам, **не оригинальный векторный файл правообладателя**. Перед передачей клиенту рекомендуется заменить на утверждённый исходный логотип. Изображения еды и интерьера — иллюстрации, не фотографии реальных блюд или помещения.

## Технически

- Статический HTML/CSS/JS, без админки и сборщиков.
- Все изображения и иконки загружаются из `assets/` внутри репозитория; нет внешних CSS/JS/fonts.
- Фильтрация карточек кухни, адаптивное меню, кликабельные адрес/телефон/соцсети.
- Запустить: открыть `index.html` в браузере.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

Это **неофициальный демонстрационный концепт** и не интернет-магазин алкоголя; цены не выдуманы. Перед публичным запуском согласовать использование фирменной символики и визуальных материалов с владельцем, проверить действительность ссылок и актуальность информации.
